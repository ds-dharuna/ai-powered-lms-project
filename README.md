# AI-Powered Learning Management System
An AI-powered Learning Management System that integrates
multilingual NLP-based tutoring, PDF question answering,
unit-wise quizzes, and learning analytics for students and instructors.

## Features
- Student & Admin dashboards
- Role-based access control
- Unit-wise quizzes with analytics
- Multilingual AI Tutor and PDF-based Q&A (RAG)
- Performance tracking & recommendations
- Notifications system

## Tech Stack
- Python, Flask
- SQLAlchemy, SQLite
- Sentence Transformers (Semantic Search)
- FAISS (Vector Search)
- Groq LLM (AI Tutor)
- Multilingual NLP (Language-aware AI responses)
- HTML, CSS, JavaScript
