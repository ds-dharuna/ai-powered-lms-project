# AI-Powered Learning Management System

## Features
- Student & Admin dashboards
- Unit-wise quizzes with analytics
- AI Tutor and PDF-based Q&A (RAG)
- Performance tracking & recommendations
- Notifications system

## Tech Stack
- Flask, SQLAlchemy
- Groq LLM API
- Sentence Transformers + FAISS
- SQLite

## Setup
```bash
git clone https://github.com/ds-dharuna/ai-powered-lms-project
cd ai-powered-lms-project
pip install -r requirements.txt
python app.py
